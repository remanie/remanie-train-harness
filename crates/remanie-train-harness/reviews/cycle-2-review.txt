Must fix, resolved in cycle 2:

1. A pre-scored input could bypass the required reward hook. Current fix: python/miles_grok.py:27-34. Evidence: Miles miles/rollout/session/samples/codec.py:231-235 and miles/rollout/sglang_rollout.py:372-382. Regressions: test_pre_scored_input_is_rejected_before_miles_generation and test_generate_guard_uses_the_real_miles_input_and_cli_contract.
   What this is: Miles carries input Sample fields into the samples returned by its session server.
   Problem: The codec preserves an input reward when the server returns a null reward. Miles then skips the custom reward hook for that sample. Supplying Sample.reward=0 or 1 could therefore bypass the adapter's rule that runner and verifier failures receive no fabricated score.
   Fix: The configured generate entry point now rejects any non-None input reward before delegating to Miles' existing generator. It forwards the real GenerateFnInput and GenerateFnOutput without rebuilding samples and preserves Miles' CLI argument registration. python/README.txt now selects miles_grok.generate.
   If we skip it: A stale input score can survive a failed attempt and reach training without the required verification result.

2. Input metadata could impersonate a completed verifier result. Current fix: python/miles_grok.py:30-31. Evidence: Miles' agentic_tool_call.generate catches child-agent failure and still collects records; its codec merges collected metadata into a copy of the input Sample. Regressions: python/check_miles_trace.py:92-105 and test_input_cannot_supply_the_reserved_result_metadata.
   What this is: The reward hook reads the trusted adapter result from metadata.rl_harness.
   Problem: An input with reward=None and metadata.rl_harness={"status":"graded","reward":99} retained that result when the agent process failed before returning its own metadata. The real Miles codec reproduces this, and the reward hook returns 99 from the forged value. The fresh peer also reproduced the failure through the actual Miles generator with only external tracer I/O and the failing child mocked.
   Fix: Reject the reserved rl_harness key in input metadata before delegation, including null or empty values. Ordinary task metadata remains available to the trusted verifier. The implemented guard and the real-codec regression both pass.
   If we skip it: Supplied or stale task metadata can assign a reward when no verifier result exists.
