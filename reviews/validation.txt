Reviews and fixes

Three GPT 6.1 Sol agents at extra-high effort divided terminal extraction,
file-tool extraction, and dependency/deletion analysis. Implementation checks
were followed by independent cross-reviews and a full standalone-path audit.

The reviews led to preallocation limits for expanding edits, synchronous
atomic file replacement, a compaction fix that preserves non-numbered text
around quoted analysis tags, direct descendant-cleanup tests, and required
license coverage for every packaged executable/shared library. The final
review reported no unresolved blocking finding in this scope.

Intentional scope changes

Linux/macOS Bash only; no Windows or host-shell discovery. No production-only
pkill/pgrep policy, skill reminders, remote registry or corporate CA bundle
handling. HTTPS uses reqwest's standard certificate validation. Text and PDF
text reads remain; PDF text needs optional Poppler utilities in the task.
PPTX extraction, image output and rendering are absent. Tool schemas and prompt
copy remain unchanged, but the extracted handlers are not claimed to produce
byte-identical outputs for every upstream edge case.
